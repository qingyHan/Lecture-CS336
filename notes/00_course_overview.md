# CS336 课程总览：从原始文本到可运行的语言模型

## 1. 课程在研究什么？

CS336
研究语言模型从零构建的全过程：数据如何收集和清洗，文本如何表示，Transformer
如何计算，训练如何优化，硬件如何高效执行，模型如何评估和后训练，以及服务如何部署。

课程采用"通过构建来理解"的方式。每一层抽象都能提高生产力，但也可能隐藏限制：如果模型太慢，要知道时间花在计算、内存访问还是通信；如果效果不好，要知道是数据、tokenizer、模型、优化器还是评估协议出了问题。

## 2. 自回归语言模型的目标

给定 token 序列 (x_1,`\ldots`{=tex},x_T)，模型按链式法则分解联合概率：

\[ p\_`\theta`{=tex}(x_1,`\ldots`{=tex},x_T)
=`\prod`{=tex}*{t=1}\^{T}p*`\theta`{=tex}(x_t`\mid `{=tex}x_1,`\ldots`{=tex},x\_{t-1}).
\]

训练时通常最小化负对数似然；生成时反复从下一个 token
的条件分布中选取一个 token，并把它追加到上下文中。

这意味着整个系统首先必须定义 token 是什么。Tokenizer
不是模型内部自动知道的天然语言单位，而是数据管线和模型接口之间的一项明确设计。

## 3. 全课程的主线

1.  **输入表示与模型**：tokenizer、Transformer 组件、参数化和训练目标。
2.  **计算与硬件**：FLOPs、内存、带宽、GPU kernel、Triton 和并行。
3.  **规模与评估**：scaling laws、推理服务、基准和可靠实验。
4.  **数据**：Common Crawl、过滤、去重、数据混合和合成数据。
5.  **后训练**：SFT、偏好优化、RLVR、对齐和多模态。
6.  **实践研究能力**：控制变量、正确性测试、性能测量、来源追踪和结果复现。

## 4. 三种知识必须分开

-   **官方内容**：以 Spring 2026 官网课表、讲义与当届 handout 为准。
-   **补充基础**：为自学者补充必要的数学、Python、PyTorch 和系统概念。
-   **工程扩展**：用于建立研究能力的额外测试、profiling、复现实验和分析。

## 5. 学习策略

每一讲采用"问题 → 直觉 → 严格定义 → 推导 → 张量形状 → 代码 → 数值示例 →
失败模式 → 实验 →
验收"的顺序。讲义读完、代码跑通都不是掌握的充分条件；需要能够独立解释和修改实现。

# 第一讲练习：课程导论与 Tokenization

**规则**：默认先独立完成，再请求提示。当前文件只给题目和少量提示，不附完整答案。

## A. 概念理解

### 题 1：token ID 是什么？

为什么 token ID `100` 不一定比 token ID `20` 对应更"大的"语义概念？请用
embedding table 解释。

**提示**：把 ID 看成数组索引，而不是测量值。

### 题 2：字符、字节与视觉字符

解释为什么一个 emoji 在 Python 字符串中可能只占一个 code point，却占多个
UTF-8 bytes。写出一段 Python 代码验证。

**验收**：解释 `len(text)` 与 `len(text.encode("utf-8"))` 的区别。

### 题 3：比较 tokenizer

分别给出字符级、字节级、词级和 BPE
的一个优点、一个缺点。你的答案必须提到词表大小与序列长度。

### 题 4：BPE 是语义分词吗？

为什么 BPE 学到的 token
不保证是词根、词缀或完整单词？举一个统计频率驱动的解释。

## B. 计算与推导

### 题 5：手算两次 merge

训练序列是 `ababab`，初始每个字符作为一个符号。假设第一次选中
`(a,b)`，请写出： 1. 初始 pair 计数； 2. 第一次 merge 后的序列； 3.
第二次 merge 后新 token 的字节内容； 4. 最终 token 序列和解码过程。

**验收**：明确说明为什么相邻替换是非重叠的。

### 题 6：压缩指标

一段文本有 1,200 个 UTF-8 bytes。Tokenizer A 输出 400 个
tokens，Tokenizer B 输出 300 个 tokens。分别计算
bytes/token。这个指标能证明 B 的语言模型质量更好吗？为什么？

### 题 7：序列长度与注意力

在标准稠密注意力的粗略复杂度 (O(T\^2)) 下，序列长度从 1,000 减到
500，注意力矩阵项数约变成原来的多少？为什么不能据此断言整个 Transformer
的运行时间恰好减半或变成四分之一？

## C. 代码阅读与调试

是必要测试，但不是充分测试？

**提示**：考虑 token 数量、速度、未知输入、训练数据分布和模型质量。

### 题 9：BPE 的顺序

如果训练时的 merge 顺序为
`[(a,b)→ab, (ab,ab)→abab]`，编码时把第二条规则放在第一条之前，可能发生什么？请用
`ababab` 说明。

### 题 10：边界条件

设计至少 5 个 tokenizer 测试输入，覆盖： - 空字符串； - ASCII 标点； -

把测试写进独立测试文件，确保解码后逐字节一致。
